# LMS-AI — Learning Management System with AI Tutor

A complete web-based Learning Management System (LMS) with an integrated AI Tutor, built using PHP, MySQL, HTML5, CSS3, and Vanilla JavaScript.

The project is designed for XAMPP, WAMP, and Laragon environments.

---

## 🚀 Project Overview

LMS-AI is a complete Learning Management System designed for:

- Students
- Instructors
- Administrators

The platform provides course management, student enrollment, lectures, assignments, quizzes, certificates, notifications, discussions, analytics, and an AI Tutor module.

The entire project is built using traditional PHP server-side architecture.
